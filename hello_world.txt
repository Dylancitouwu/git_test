Para copiar el repositorio de Github en el espacio local de Git, tenemos que copiar el "Link" en la parte de Code de Github
y poner la de SSH con el siguiente comando

<git clone (ctrl + shift + V)>

Lo cual pegara el repositorio y se cargaran los datos para empezar a usarlo

Ahora, para poder ver el estado de nuestro repositorio y saber que si estamos en este usamos el comando

<git remote -v>




Pensemos que vamos a aniadir algo al Github, tenemos que iniciar creando lo que sea que vamos a hacer, en este caso es un archivo
de texto

Podemos hacerlo con el comando <touch "Nombre del archivo".txt>

Si queremos revisar el estado de nuestro cambio usar el comando

<git status>


Ahora nos saldra en rojo el cambio que hemos hecho dentro de nuestro repositorio de Github

Lo que tenemos que hacer es agregarlo para que entre a la fase de Staging con el comando

<git add "Nombre del archivo".txt> #Aplica para cualquier tipo de archivo no solo texto


Ahora si vemos el estado de nuestro repositorio saldra en verde pero eso no quiere decir que se haya actualizado el cambio que 
hicimos, mas bien es como una lista de espera para aceptar el cambio.

Ahora bien, solo nos queda un paso para terminar de hacer el commit. Con el comando:

<git commit -m "Add "Nombre del archivo".txt">

Se va a hacer el cambio que hemos querido para (en este caso) el documento de texto que hemos configurado

Eso seria todo por esta leccion, ahora wa guardar con otro mensaje, no es necesario commitear con (Add), se puede hacer
con otras palabras explicando el cambio o los cambios que hemos hecho
